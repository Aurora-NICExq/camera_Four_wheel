# control.c 逐行注释

> 行号与源文件一致。

实现横向 PD 转向、微分低通、舵机限幅与占空比上升斜率限制（`DUTY_SLEW_UP`）。不直接操作硬件，输出由 `motor.c` / `cpu0_main.c` 消费。

## control_update — PD 环与占空比斜率

```c
// L38: 每帧图像处理完成后调用：输入巡线结果，输出舵机与占空比。
// L39: 开括号。
// L40: 从 `track_info_t` 取出本帧横向误差（像素，已含前瞻/保持逻辑）。
// L41: 临时浮点，用于占空比目标计算。
// L42: 无符号目标占空比（限幅前）。
// L43: 本帧原始微分（浮点）。
// L44: PD 合成后的舵机 PWM（限幅前，有符号）。
// L45: （空行。）
// L46: 计算误差差分：本帧减上一帧，即离散微分 d_raw。
// L47: 更新 `g_prev_error` 为当前误差，供下一帧使用。
// L48: 一阶低通：`g_d_filt += α*(d_raw - g_d_filt)`，抑制图像噪声对 D 项的放大。
// L49: （空行。）
// L50-L51: 舵机 PWM = 中位 + SERVO_DIR * (Kp*error + Kd*g_d_filt)；
//          SERVO_DIR=-1 决定误差符号与转向方向的对应关系。
// L52: 限幅后写入 `out->servo_pwm`。
// L53: （空行。）
// L54: 目标速度取菜单设定的 `drive_duty_base`（浮点转换）。
// L55-L58: 负值钳 0（防御性，正常无符号 duty 不会为负）。
// L59: 转为 uint16_t 目标占空比。
// L60: 硬上限 DUTY_HARD_CAP（6000）。
// L61: （空行。）
// L62-L66: 占空比上升斜率限制（duty slew up）：
//   若 target > g_duty_now，每帧最多增加 DUTY_SLEW_UP（120）；
//   实现发车软启动，避免瞬时大电流。
// L67-L70: 若 target ≤ g_duty_now（减速或目标变低），立即跟到 target，无下降斜率限制。
// L71: （空行。）
// L72: 输出经斜率限制后的 `out->duty`。
// L73: 输出本帧使用的误差，供调试屏与遥测。
// L74: 闭括号，`control_update` 结束。
```

## 数据流小结

| 阶段 | 变量 | 说明 |
|------|------|------|
| 输入 | `ti->error` | `image_process` 前瞻滑窗得到的横向误差 |
| P 项 | `steer_kp * error` | 比例转向 |
| D 项 | `steer_kd * g_d_filt` | 滤波后的误差变化率 |
| 输出 | `out->servo_pwm` | 中位 ± PD，再经 `control_servo_clamp` |
| 输出 | `out->duty` | `drive_duty_base` 经硬顶与上升斜率限制 |
