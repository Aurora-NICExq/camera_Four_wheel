# config.h 逐行注释

> 行号与源文件一致。

本文件集中定义图像尺寸、前瞻误差、八邻域巡线、十字补线、舵机、PD 控制、占空比限速、按键与三档预设等全局常量。菜单与 `control.c` 通过 `extern volatile` 引用其中部分运行时可改项（Kp/Kd 等默认值由此处给出）。

## 前瞻误差（lookahead）

单段滑窗前瞻：`[look_far - span, look_far)` 内各行 mid 均匀平均得 error。`look_far` 由菜单项 Look Far 设定，默认见 `STEER_LOOK_FAR_DEFAULT`。

```c
// L21: 注释：以下为前瞻（转向误差聚合）相关参数。
// L22: （空行，分隔注释与宏。）
// L23: 前瞻滑窗跨度 20 行；与 `look_far` 一起决定参与误差的行区间。
// L24: Look Far 菜单默认值 115（靠近图像顶端，看更远）。
// L25-L26: Look Far 允许的最大行号 = IMG_H - 1 = 119，不能超过图像最后一行。
// L27-L29: 编译期检查：span 必须在 [1, look_far_max) 内，否则 #error。
// L30-L33: 编译期检查：默认 look_far 必须 ≤ max 且 > span，否则 #error。
// L34: 盲区保持（两边都丢线）时，最多沿用上一帧误差 20 帧，之后归零。
```
